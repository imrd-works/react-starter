# Архитектура

Проект построен по [Feature-Sliced Design](https://feature-sliced.design/).
Все правила ниже **проверяются ESLint** (`eslint.config.js`, блок `architecture`) —
нарушение не пройдёт ни коммит, ни CI.

## Слои

```
app        → инициализация приложения: провайдеры, роутер, middleware, i18n, глобальные стили
pages      → страницы; собирают виджеты и фичи, описывают свой маршрут (route.ts)
widgets    → самостоятельные блоки интерфейса (header, sidebar)
features   → действия пользователя, приносящие ценность (auth, contact-form)
entities   → бизнес-сущности и их данные (session, user)
shared     → переиспользуемое без бизнес-логики (ui, api, lib, config, styles)
```

### Правило 1. Импорт только вниз

Слой может импортировать только слои **ниже** себя:

| Откуда     | Можно импортировать                 |
| ---------- | ----------------------------------- |
| `app`      | всё                                 |
| `pages`    | widgets, features, entities, shared |
| `widgets`  | features, entities, shared          |
| `features` | entities, shared                    |
| `entities` | shared                              |
| `shared`   | только shared (сегменты друг друга) |

### Правило 2. Слайсы одного слоя изолированы

`features/auth` не может импортировать `features/contact-form`, а `entities/user` —
`entities/session`. Если двум слайсам нужно взаимодействовать, их связывает слой выше
(страница или виджет), передавая данные через props/параметры.

Пример из кода: `useCurrentUser({ enabled })` не читает сессию сам — флаг передаёт
`widgets/header`, который вправе импортировать обе сущности.

### Правило 3. Только публичный API

Чужой слайс импортируется **только через его `index.ts`**:

```ts
import { LoginForm } from '@/features/auth' // ✔
import { LoginForm } from '@/features/auth/ui/LoginForm' // ✖ boundaries/dependencies
```

Внутри своего слайса — относительные импорты (`../model/useLogin`). Глубокие
относительные импорты (`../../`) запрещены: они почти всегда выходят за границу слайса.

Экспортируйте только то, что реально используется снаружи — лишнее найдёт Knip.

### Правило 4. Тестовый код не попадает в прод

`shared/testing` и `shared/mocks` доступны только из `*.test.ts(x)` и слоя `app`
(dev-воркер MSW, setup тестов).

## Структура слайса

```
features/auth/
├── api/          # запросы к бэкенду (через `api` из @/shared/api)
├── model/        # состояние, хуки, схемы валидации, бизнес-логика
├── ui/           # компоненты (PascalCase.tsx + PascalCase.module.scss + .test.tsx)
├── locales/      # en.json, ru.json — namespace = имя слайса
└── index.ts      # публичный API
```

Сегменты создаются по необходимости. Страница дополнительно содержит `route.ts`.
Новый слайс со всеми соглашениями: `npm run generate:slice -- <layer> <name>`.

## Соглашения об именовании

| Что                        | Формат      | Пример                   |
| -------------------------- | ----------- | ------------------------ |
| Папки                      | kebab-case  | `contact-form/`          |
| Компоненты (`ui/**/*.tsx`) | PascalCase  | `LoginForm.tsx`          |
| Остальные `.ts`            | camelCase   | `sessionStore.ts`        |
| CSS-классы                 | camelCase   | `styles.linkActive`      |
| Экспорты                   | именованные | `export function Header` |

Default-экспорты запрещены (кроме конфигов): именованные лучше рефакторятся и ищутся.

## Состояние

- **Серверное** (всё, что пришло с бэкенда) — только TanStack Query. Ключи кэша
  описываются фабрикой рядом с сущностью (`userQueries.me()`).
- **Клиентское** (токен, UI-настройки) — Zustand. Минимум данных, без дублирования
  серверного кэша.
- **Локальное** — `useState` в компоненте.

## API

- Слайсы используют только `api` из `@/shared/api`; импорт транспортной библиотеки
  напрямую запрещён ESLint. Транспорт — нативный `fetch`; сменить его можно в одном
  файле (`fetchClient.ts`), реализовав интерфейс `ApiClient`.
- Ошибки нормализуются в `ApiError` и автоматически показываются тостом.
  `{ silent: true }` — обработать ошибку самому, `{ toast: { success } }` — тост успеха.
- 401 вызывает `onUnauthorized` (сброс сессии и кэша). `shared` не знает о сессии —
  колбэки внедряет слой `app` (`app/setup/configureApp.ts`).
- DTO берутся из `openapi.json`: `ApiSchemas['User']`. После изменения контракта —
  `npm run generate:api`.

## Маршруты и доступ

- Каждая страница описывает `route.ts` с `lazy` — отдельный чанк на страницу.
- Пути — константы `ROUTES` из `@/shared/config` (страницы не импортируют друг друга).
- Доступ — через middleware React Router (`app/router/middleware`):
  `requireAuth` (гость → `/login?redirect=…`) и `guestOnly`.
- `redirect` после логина проходит через `getSafeRedirect` — защита от open redirect.

> Используйте функциональную форму `lazy: async () => ({ Component })`.
> Объектная форма `lazy: { Component }` в React Router 8.4 ломается при повторном
> использовании маршрутов в другом роутере (тесты, HMR).

## Стили

- Компоненты — только `*.module.scss`. Классы camelCase, для каждого модуля
  генерируется `.d.ts` — опечатка в `styles.xxx` становится ошибкой TypeScript.
- Цвета, z-index, шрифты — только через токены (`var(--color-…)`): хардкод
  отклоняет Stylelint.
- Токены — `shared/styles/tokens`, миксины — `@use 'shared/styles/mixins' as *`.
- Раскладка — компонентами `Stack` и `Container`, а не глобальными утилитарными классами.

## i18n

- Весь текст интерфейса — в `locales/*.json`. Кириллица в коде запрещена ESLint.
- Ключи типизированы: `t('несуществующий.ключ')` — ошибка компиляции.
- Язык по умолчанию (`en`) встроен в бандл, остальные грузятся лениво.
- Новый namespace регистрируется в `app/i18n/resources.ts`.
- `npm run i18n:check` сверяет наборы ключей всех языков.

## Тесты

- Тесты лежат рядом с кодом: `Button.tsx` → `Button.test.tsx`.
- Тестируйте поведение через роли и тексты (Testing Library), а не реализацию.
- Сеть мокается MSW (`shared/mocks/handlers.ts`); в тесте можно переопределить
  ответ через `server.use(...)`.
- Для компонентов с роутером/запросами — `renderWithProviders` из `@/shared/testing`.
- Пороги покрытия — «храповик»: повышаем по мере роста, никогда не снижаем.
- Unit-тесты идут без React Compiler (его мемоизация искажает покрытие веток);
  скомпилированный бандл проверяют e2e-тесты.
